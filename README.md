# AfricanaAI Prototype

AfricanaAI is a **free prototype AI tool** for translating text between multiple African languages.  
This prototype is built with **Python** and **Streamlit** using the Hugging Face **NLLB-200** multilingual model.

## Supported Languages
- Hausa
- Yoruba
- Igbo
- Swahili
- Somali
- Amharic
- Fulfulde
